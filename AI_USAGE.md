# Декларація використання штучного інтелекту

## Лабораторна робота №1
- **Інструмент:** LLM-асистент (Gemini).
- **Завдання:** шаблонізація коду профілювання даних (`pandas`, `jupytext`), генерація структури словника даних `docs/lab01/data_dictionary.md` та схеми архітектури `docs/lab01/architecture_v0.png`.
- **Спосіб перевірки:** виконання розрахунків на локальних CSV-файлах пакета `cityflow_S08_base_v1.zip`, перевірка цілісності через `jupyter nbconvert`.

## Лабораторна робота №2
- **Інструмент:** LLM-асистент (Gemini).
- **Завдання:** проєктування схем PostgreSQL (`stg`, `core`, `audit`), написання SQL DDL та функції безпечного парсингу `stg.try_cast_timestamptz`, оптимізація конвеєра на `psycopg 3` (COPY streaming), розробка тестів надійності та ідемпотентності (`pytest`), побудова ER-діаграми та верстка Typst-шаблону.
- **Спосіб перевірки:** застосування міграцій до Docker PostgreSQL 16, звірка 100% файлового балансу запитами до `audit.run_file_stats`, верифікація транзакційного відкату автотестами `pytest tests/lab02/test_pipeline.py`.
